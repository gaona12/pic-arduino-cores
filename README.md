# PIC Arduino Cores — Program PIC microcontrollers from the Arduino IDE

> **🇬🇧 English** · [🇪🇸 Español más abajo](#-español)

Program **8-bit Microchip PIC microcontrollers (PIC16F and PIC18F)** directly from
the **Arduino IDE**, writing the exact same `setup()` / `loop()` sketches you'd
write for an Arduino Uno. Pick your PIC from the board menu, just like you pick an
ESP32.

This project makes the PIC a **first-class citizen** of the Arduino IDE: its own
cores, its own build chain, its own uploader — without ever generating AVR code or
reverse-engineering any compiler.

**22 chips supported** (10× PIC16F + 12× PIC18F). The only external dependency is
Microchip's **XC8** compiler; everything else (transpiler, uploader, library
checker) is plain **C** that auto-compiles with the `clang` already on macOS.

```c
// This Arduino-Uno-style sketch compiles and runs on a PIC16F877A:
Servo myServo;

void setup() {
  Serial.begin(9600);
  myServo.attach(9);
}
void loop() {
  myServo.write(90);
  Serial.println(analogRead(0));   // number, just like on the Uno
  delay(1000);
}
```

## Why this exists

XC8 only compiles **C**, not C++. The Arduino language is C++. So instead of
building a C++ compiler for PIC (a multi-year effort), this project uses a small
**transpiler** that translates the Arduino "dictionary" (`Serial.print`,
`myServo.attach`, ...) into the C functions of a hand-written Hardware Abstraction
Layer (HAL). This is the same architecture used by commercial tools like Flowcode
and Niple: generate C, then hand it to the native PIC compiler.

## Features

- ✅ **Arduino Uno syntax** — `setup()`/`loop()`, `Serial.print()`, `digitalWrite()`, etc.
- ✅ **22 PIC chips** — PIC16F84A/628A/88/690/873A/874A/876A/877A/886/887 and PIC18F2455/2520/2550/2620/452/458/4455/4520/4525/4550/4580/4620.
- ✅ **Full peripherals** — Digital I/O, ADC, PWM, UART (Serial), I2C, SPI, EEPROM, LCD.
- ✅ **Library system with per-chip compatibility filter** — libraries declare what
  they need (I2C, RAM, excluded chips); a C checker (`libcheck`) blocks the build with
  a clear message if the chosen PIC can't support them.
- ✅ **C runtime ecosystem** — the shipping pieces (transpiler, uploader, checker) are
  C that self-compiles with clang, so a user only needs XC8.
- ✅ **USB upload** via TinyBootloader, or ICSP via PICkit 2 (pk2cmd).

> **Open goal — reuse Arduino libraries at 100%.** The current transpiler handles the
> Arduino "dictionary" and single-instance library objects. A full **C++ → C translator**
> (so unmodified Arduino libraries just work) is a welcome future goal, and the project
> is **not locked to C for it** — it may be built in Python or any language if that gets
> us a correct, complete translator faster. See [docs/ROADMAP.md](docs/ROADMAP.md).

## Install

### Option A — Board Manager (one-click, like the ESP32) ⭐

1. Arduino IDE → **Settings / Preferences** → **Additional boards manager URLs**,
   add:
   ```
   https://raw.githubusercontent.com/gaona12/pic-arduino-cores/main/board-manager/package_pic_index.json
   ```
2. **Tools → Board → Boards Manager**, search **"PIC"**, install
   *PIC16F Boards (XC8)* and/or *PIC18F Boards (XC8)*.
3. Install **MPLAB XC8** separately (see [docs/INSTALL.md](docs/INSTALL.md)).
4. **Tools → Board** → pick your PIC.

> The Board Manager index and release assets are generated by
> `tools/make_board_package.sh`. See [docs/INSTALL.md](docs/INSTALL.md) for
> publishing new versions.

### Option B — Manual (copy into the sketchbook)

1. Copy the `hardware/pic/pic16` (and/or `pic18`) folders into your Arduino
   sketchbook so they end up at:
   ```
   ~/Documents/Arduino/hardware/pic/pic16/boards.txt
   ~/Documents/Arduino/hardware/pic/pic18/boards.txt
   ```
2. Install **MPLAB XC8** (the installer script `instalar.sh` can fetch it).
3. Restart the Arduino IDE → **Tools → Board** → pick your PIC.

Full guide: [docs/INSTALL.md](docs/INSTALL.md).

## How it works (the pipeline)

```
Your sketch (.ino, Arduino syntax)
        │
        ▼
  transpile.c  ──►  C source   (translates Serial.print, myServo.write, ...)
        │
        ▼
  libcheck.c   ──►  compatibility check against the chosen chip
        │
        ▼
     XC8        ──►  .hex  (native PIC machine code)
        │
        ▼
  tinybld_load.c / pk2cmd  ──►  flashes the PIC (USB bootloader or PICkit 2)
```

   agrega:

   ~/Documents/Arduino/hardware/pic/pic16/boards.txt
